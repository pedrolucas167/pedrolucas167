## 🚀 Featured Personal Projects

### ⚡ Order Matching Engine
**Go · Concurrency · Performance · Data Structures**

A high-performance trading order matching engine designed around **Price-Time Priority (FIFO)**.

The project explores systems-level engineering concepts such as:

- Sharded order books by trading symbol
- Limit and market orders
- Concurrent reads and writes
- Lock-free snapshots using `atomic.Pointer`
- Backpressure and buffered channels
- `sync.Pool` for allocation reduction on the hot path
- Heap-based price levels
- Benchmarks for throughput and concurrent matching

→ [View project](./order-matching-engine)

- Real-time state visualization
- Interactive 3D visualization
